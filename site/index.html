A fast, native database client.

SQL and NoSQL in one fast, native app. Relational, document, key-value, time-series and analytical databases share one editor that knows your schema, one results grid and one set of tools, in a small client written in Rust.

Recorded live at normal speed: SQLite, Redis and CouchDB.

What it does

Editor
Completion for tables, columns, joins and aliases from the live schema. Go to definition, rename refactoring, find and replace, and warnings for names that don't exist.
Explorer
Every object kind: tables, views, materialized views, routines, triggers, sequences, indexes, collections and keys. Several databases per server, grouped into projects.
Results
A virtualized grid that only draws what's on screen. Sort, filter, edit rows through a script you review first, and export to CSV, JSON, SQL or Markdown.
Documents
MongoDB and CouchDB results as documents, with every field as a tree, and CouchDB attachments with previews, links and downloads.
Query plans
EXPLAIN and EXPLAIN ANALYZE as a tree with costs and timings.
Schema tools
Schema compare with the migration script, ER diagrams, table and routine editing, and CSV import.
Production safety
Read-only and production connections, confirmation before risky statements, manual transactions, and no automatic sign-in retries that could lock an account.

Install

macOS
curl -fsSL https://raw.githubusercontent.com/hayes-roach/DataBug/main/install.sh | sh
Linux
curl -fsSL https://raw.githubusercontent.com/hayes-roach/DataBug/main/install.sh | sh
Windows
irm https://raw.githubusercontent.com/hayes-roach/DataBug/main/install.ps1 | iex

The scripts verify the download against the release's checksums. Run them again to update. Installers are on the releases page.
