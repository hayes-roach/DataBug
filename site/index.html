One fast client for every database you use

DataBug is a memory-light database client written in Rust. SQL with completion that knows your schema, Redis commands, MongoDB and CouchDB documents, query plans, schema compare and more, for 17 databases.

Download DataBug Source on GitHub

Also for macOS, Windows and Linux · Apache-2.0

Recorded live, nothing sped up: SQL completion on SQLite, Redis keys and commands, CouchDB documents with attachments.

Everything you reach for, without the weight

Native, GPU-drawn and quick to start. Results stream into a virtualized grid that only draws the rows on screen, so large results scroll smoothly.

An editor that knows your schema

Completion for tables, columns, joins and aliases; go to definition, rename refactoring, find and replace, and inspections that flag unknown names.

Every object in the explorer

Tables, views, materialized views, routines, triggers, sequences, indexes and keys, across several databases per server and grouped into projects.

A fast results grid

Sort, filter, edit rows in place with a reviewed script, and export to CSV, JSON or SQL. Big results stay smooth.

Query plans you can read

Explain and explain-analyze as a tree with costs and timings, for PostgreSQL, MySQL, SQL Server, SQLite and more.

Redis, the way you type it

Commands as in redis-cli with completion for 185 commands, your keys and hash fields. Replies come back as tables shaped for the command.

Documents and attachments

MongoDB and CouchDB results as documents: every field as a tree, attachments with previews, links and downloads.

Schema compare and ER diagrams

Diff two schemas and get the migration script. See tables and their relationships as a diagram you can arrange.

Guard rails for production

Read-only and production connections, confirmations for risky statements, manual transactions, and no automatic sign-in retries that lock accounts.

17 databases, one window

Each with its own driver, introspection and console language. PostgreSQL, MySQL, SQLite, CockroachDB, TimescaleDB, QuestDB, Cassandra, CouchDB, InfluxDB, DuckDB and Redis are tested against live servers.

Install in one line

The scripts download the latest release, check it against its published checksums and install it. Run them again to update.

curl -fsSL https://raw.githubusercontent.com/hayes-roach/DataBug/main/install.sh | sh

Or download the .dmg from the latest release and drag DataBug to Applications.
